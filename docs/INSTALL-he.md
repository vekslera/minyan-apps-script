# התקנת מערכת הנוכחות למניין חדש

<div dir="rtl">

ההתקנה נעשית פעם אחת, במחשב, ולוקחת כ-20 דקות. לשלב המיקום (6) צריך להיות בבית הכנסת עם טלפון.

**לפני שמתחילים:**

- חשבון Gmail של המניין. מומלץ חשבון נפרד ולא האישי שלכם: דף הרישום רץ בחשבון הזה.
- בדפדפן — להיות מחוברים **רק** לחשבון המניין (או לפתוח לו פרופיל Chrome נפרד). כמה חשבונות מחוברים יחד מבלבלים את Google.
- קישור ההעתקה שקיבלתם מאלכס.

שמות התפריטים כתובים בעברית ובאנגלית, כי הם תלויים בשפת החשבון.

## 1. יצירת עותק

פותחים את קישור ההעתקה ← **יצירת עותק (Make a copy)**. אפשר לתת שם, למשל "נוכחות — מניין מנחה וערבית".
העותק נשמר ב-Drive של חשבון המניין, יחד עם הקוד שלו.

## 2. הגדרה ראשונית

1. בגיליון החדש מחכים כמה שניות לתפריט **מניין** בסרגל העליון (אם אינו מופיע — מרעננים את הדף).
2. **מניין ← הגדרה ראשונית**.
3. Google מבקשת אישור: **המשך** ← בוחרים את חשבון המניין ← במסך "Google לא אימתה את האפליקציה" לוחצים **מתקדם (Advanced)** ← **מעבר אל… (לא בטוח)** ← **אישור (Allow)**. זה תקין: האפליקציה שלכם ופועלת רק בחשבון שלכם. (Google תבקש גם הרשאה לשלוח דואר ולפעול כשאינכם מחוברים — זו ההתראה למפתח על תקלות.)
4. אם ההגדרה לא רצה אחרי האישור — שוב **מניין ← הגדרה ראשונית**.
5. בסוף מופיע **קוד הגבאי**. אם פספסתם אותו: הוא מופיע בחלון של **מניין ← קישור לדף הרישום** (אחרי שלב 4), ואפשר להחליף אותו ב**מניין ← שינוי קוד גבאי**.

## 3. פרסום דף הרישום

1. בגיליון: **תוספים (Extensions) ← Apps Script**. נפתחת לשונית חדשה.
2. **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
3. ליד "בחירת סוג" לוחצים על גלגל השיניים ⚙ ← **אפליקציית אינטרנט (Web app)**.
4. **הפעלה בתור (Execute as): אני (Me)**. **למי יש גישה (Who has access): כל אחד (Anyone)** — לא "כל מי שיש לו חשבון Google".
5. **פריסה (Deploy)**. אם מתבקש אישור — כמו בשלב 2.
6. מעתיקים את **כתובת אפליקציית האינטרנט (Web app URL)** — מתחילה ב-`https://script.google.com` ומסתיימת ב-`exec`.

פורסים **פעם אחת בלבד**. פריסה חדשה נוספת יוצרת כתובת חדשה, והקישורים וה-QR שהודפסו יפסיקו לעבוד.

## 4. חיבור הדף לגיליון

חוזרים לגיליון ← **מניין ← כתובת דף הרישום (הדבקה)** ← מדביקים את הכתובת (Ctrl+V) ← **אישור**.
נפתח חלון עם הקישור לדף הרישום, קוד QR, קוד הגבאי וקישור ל**כלי הגבאי**. בודקים: **פתיחה** צריכה לפתוח את דף הרישום עם שם המניין.
מאותו מקום מחליפים את הכתובת אם הודבקה כתובת שגויה. אחר כך, החלון נפתח ב**מניין ← קישור לדף הרישום**.

## 5. הגדרות המניין

נכנסים לכלי הגבאי (עם קוד הגבאי) ← **הגדרות**:

- שם המניין, **ימי המניין**, שעות הרישום העצמי;
- תחילת התקופה וסופה;
- אחוז נוכחות להגרלה ולדוח לרבי (**0 = כבוי**).

שמירה. (אותן הגדרות נמצאות גם בגיליון "הגדרות".)

## 6. מיקום בית הכנסת — בבית הכנסת, עם טלפון

כלי הגבאי ← **מיקום בית הכנסת** ← עומדים באמצע האולם ← **מדידה** ← **קביעה כמיקום בית הכנסת**. רדיוס מומלץ: 40–60 מטר.
עד שהמיקום נקבע, אפשר להירשם מכל מקום.

## 7. ניסיון והפצה

1. סורקים את ה-QR בטלפון ונרשמים. בודקים שהשם הופיע בגיליון **נוכחות**.
2. מדפיסים את ה-QR ותולים בבית הכנסת, ושולחים את הקישור בקבוצת הוואטסאפ של המניין.
3. קוד הגבאי — לגבאים בלבד.

## 8. עדכונים ועזרה

כדי לקבל עדכונים לתוכנה ועזרה בתקלות: **שיתוף (Share)** בגיליון ← מוסיפים את `vekslera@gmail.com` כ**עורך (Editor)**.

- לא משנים את הקוד בעורך Apps Script.
- לא יוצרים פריסה חדשה (ראו שלב 3).
- הוראות שימוש יומיומי — בגיליון **הוראות**.
